# 결정 사항

- 2026-11-10: 웹 앱은 Vercel 대신 localhost에서만 돌리고, Claude Code 안에서만 실행한다.
- 2026-11-10: 이사 명단 추출은 외부 LLM API(OpenRouter) 대신 열려 있는 Claude Code 세션이 파일 큐로 처리한다 (`claude -p`를 요청마다 호출하는 방식은 기각).
- 2026-11-10: 별도 저장소였던 `board-tracker-web`을 이 저장소의 `web/`으로 합친다. 예전 git 이력은 가져오지 않는다.
- 2026-11-10: 런타임 파일(큐, 하트비트, 캐시 DB, 회사 목록)은 모두 `web/.runtime/`에 두고 git에서 제외한다.
- 2026-11-10: 캐시는 Neon Postgres 대신 로컬 SQLite(`node:sqlite`), 회사 목록은 Vercel Blob 대신 로컬 JSON 파일을 쓴다.
- 2026-11-10: 로컬 전용이므로 로그인(접속 코드·JWT)을 없애고, 대신 dev 서버를 `127.0.0.1`에만 바인딩한다.
- 2026-11-10: Claude 세션이 대기 중인지는 감시 스크립트의 하트비트(60초)로 판단하고, 없으면 기다리지 않고 바로 안내한다.
- 2026-11-10: 추출 결과는 섹션 텍스트에 있는 정보만 쓴다. 대표이사 여부가 본문에 없으면 표시하지 않는다.
- 2026-11-10: 최상위 Python CLI는 이번 전환 범위에서 제외한다.
- 2026-11-10: 대시보드 기본 조회 범위는 올해를 포함한 최근 4년으로 자동 설정한다.
